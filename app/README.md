# 買掛管理 v0.5.1

起動はデスクトップの「買掛管理」ショートカットから。Node.js 22.13以降が必要です。

- データ: `%LOCALAPPDATA%\KaikakeManager\data\kaikake.db`
- 起動時に日次バックアップを1日1回作成し、日次分は直近30世代を保持
- 復元: アプリを終了後、インストール先で `node restore-db.js kaikake_daily_2026-11-20.db` のように実行。復元前に現DBをバックアップ
- インストーラーは `data/` と `backup/` を上書きしません
- 本版は試験版です。銀行振込の実行や会計仕訳の自動生成はしません。

## テスト用DBの作成

ZIPを展開し、`app` フォルダの「テスト用DB作成.bat」を実行すると、`app/test-db/kaikake_test.db` に架空データ入りのSQLite DBを作成します。更新後はインストール先からも実行できます。Node.js 22.13以降が必要です。

別のフォルダに出力する場合は、`app` フォルダで `node create-test-db.mjs "出力先フォルダ"` を実行します。既に同名のファイルがある場合は作成を中止します。生成時に通常のDBやバックアップにはアクセスしません。

画面で確認する場合は、ZIPから別に展開したアプリの `app/data` フォルダを作成し、生成したDBを `kaikake.db` という名前で配置します。通常のアプリを終了してから、展開した側の「起動.bat」で起動してください。送金一覧は、送金予定で2026年11月・2027年1月、送金実績で2026年11月を選択すると確認できます。
